# Карта сборки в Битрикс24.Сайты

Это пошаговая инструкция: что нажать в конструкторе и какой текст вставить. Тексты взяты из ТЗ без изменений по смыслу. Визуальный эталон — `preview/index.html` и скриншоты в `screenshots/`. Концепция, палитра и правила дизайна — `DESIGN.md`.

> **Главное про дизайн.** На бесплатном тарифе своего CSS/HTML нет (только на коммерческих тарифах **[проверено]**). Поэтому уникальность держится на трёх вещах, доступных бесплатно: **собственные иллюстрации** из `images/`, **цвета фона и элементов** в «Дизайне» каждого блока и **выбор блоков**. Не берите готовый «шаблон сайта» целиком: начните с пустого и добавляйте блоки по этой карте.

> Метки: **[проверено]** — подтверждено справкой Битрикс24 (ссылки внизу). **[проверить на месте]** — в справке не описано, смотрите в своём редакторе.

## Шаг 0. Подготовка аккаунта (сначала основной сценарий, потом дизайн)

1. Войдите в свой Битрикс24 и посмотрите тариф: **Настройки → Тариф** (или значок тарифа вверху).
   - Должен быть **Бесплатный** тариф, а не **Демо**. В демо-режиме публикация сайтов и CRM-формы недоступны, а собственный HTML/JS запрещён. **[проверено]**
   - На бесплатном тарифе можно опубликовать **один активный сайт** на служебном домене `*.bitrix24site.ru`. Свой домен и счётчики аналитики доступны только на платных тарифах. **[проверено]**
   - Если у вас уже опубликован другой сайт, **не заменяйте его**. Снимите его с публикации сами или согласуйте это заранее.
2. Создайте **минимальный черновик**: **Сайты и магазины → Сайты → Создать сайт → «Пустой шаблон»** (или ближайший пустой вариант). Название: `Хостинг для проектов`.
3. Добавьте на страницу заголовок (любой текстовый блок) и **блок CRM-формы** (категория **«Формы»** в библиотеке блоков).
   - При создании первой CRM-формы на бесплатном тарифе система попросит **подтвердить номер телефона по СМС**. **[проверено]** Порядок: ввести номер → «Получить СМС» → ввести код → «Подтвердить» → «Завершить». Один номер подходит максимум для пяти Битрикс24. Код вводите только в окне Битрикс24, никому его не пересылайте.
4. **Опубликуйте** черновик: иконка облака → «Опубликовать сайт». Откройте публичную ссылку **в окне инкогнито** и отправьте тестовую заявку. Найдите её в CRM (подробно в `FORM_CRM.md`).
5. Только если заявка дошла, переходите к полной сборке.

## Шаг 2. Как работают якоря и кнопки (общее для всех блоков)

- **Якорь блока** задаётся в окне **«Редактировать»** этого блока. По умолчанию он имеет вид `block123`. Замените его на имя из таблицы ниже. В имени допустимы только латиница, цифры, `-`, `_` и `.`, первым символом должна быть буква. **[проверено: справка API и сторонний разбор; точное место поля — проверить на месте]**
- **Кнопка → раздел:** нажмите на кнопку, в поле **«Действие по клику»** выберите **«Перейти к блоку»** и укажите нужный блок. Способ открытия — **«в этом же окне»**. **[проверено]**
- Если в пункте меню нет варианта «Перейти к блоку», впишите в поле ссылки `#имя_якоря`, например `#plans`. **[проверить на месте]**
- **Сохранить** → изменения публикуются автоматически. Если не появились: облако → «Опубликовать сайт». **[проверено]**

| Раздел | Якорь |
| --- | --- |
| Шапка / первый экран | `top` |
| Что можно разместить | `services` |
| Подход к качеству | `approach` |
| Панель управления | `panel` |
| Варианты размещения | `plans` |
| Как начать | `start` |
| Вопросы и ответы | `faq` |
| Обратная связь | `contact` |

| **Индивидуальная конфигурация** | Для нескольких сервисов, нестандартного стека или особых требований. Начнём с описания вашей задачи. | «Обсудить конфигурацию» → блок `contact` |

**Текст под карточками** (отдельный блок «Текст»): Объём памяти, диска, процессорные лимиты, дополнительные возможности и стоимость определяются при подборе. Модель процессора указывает на серверную линейку и не означает выделение всего процессора одному проекту.

**Не добавлять:** цены, скидки, «до N игроков», конкретные ГБ.

### Блок 7. Как начать — якорь `start`

### Блок 8. Вопросы и ответы — якорь `faq` (аккордеон, дополнительная функция №1)

1. Облако → **«Опубликовать сайт»**.
