# Карта сборки в Битрикс24.Сайты

Это пошаговая инструкция: что нажать в конструкторе и какой текст вставить. Тексты взяты из ТЗ без изменений по смыслу. Визуальный эталон — `preview/index.html` и скриншоты в `screenshots/`.

> Метки: **[проверено]** — подтверждено справкой Битрикс24 (ссылки внизу). **[проверить на месте]** — в справке не описано, смотрите в своём редакторе.

---

## Шаг 0. Подготовка аккаунта (сначала основной сценарий, потом дизайн)

1. Войдите в свой Битрикс24 и посмотрите тариф: **Настройки → Тариф** (или значок тарифа вверху).
   - Должен быть **Бесплатный** тариф, а не **Демо**. В демо-режиме публикация сайтов и CRM-формы недоступны, а собственный HTML/JS запрещён. **[проверено]**
   - На бесплатном тарифе можно опубликовать **один активный сайт** на служебном домене `*.bitrix24site.ru`. Свой домен и счётчики аналитики доступны только на платных тарифах. **[проверено]**
   - Если у вас уже опубликован другой сайт, **не заменяйте его**. Снимите его с публикации сами или согласуйте это заранее.
2. Создайте **минимальный черновик**: **Сайты и магазины → Сайты → Создать сайт → «Пустой шаблон»** (или ближайший пустой вариант). Название: `Хостинг для проектов`.
3. Добавьте на страницу заголовок (любой текстовый блок) и **блок CRM-формы** (категория **«Формы»** в библиотеке блоков).
   - При создании первой CRM-формы на бесплатном тарифе система попросит **подтвердить номер телефона по СМС**. **[проверено]** Порядок: ввести номер → «Получить СМС» → ввести код → «Подтвердить» → «Завершить». Один номер подходит максимум для пяти Битрикс24. Код вводите только в окне Битрикс24, никому его не пересылайте.
4. **Опубликуйте** черновик: иконка облака → «Опубликовать сайт». Откройте публичную ссылку **в окне инкогнито** и отправьте тестовую заявку. Найдите её в CRM (подробно в `FORM_CRM.md`).
5. Только если заявка дошла, переходите к полной сборке.

## Шаг 2. Как работают якоря и кнопки (общее для всех блоков)

- **Якорь блока** задаётся в окне **«Редактировать»** этого блока. По умолчанию он имеет вид `block123`. Замените его на имя из таблицы ниже. В имени допустимы только латиница, цифры, `-`, `_` и `.`, первым символом должна быть буква. **[проверено: справка API и сторонний разбор; точное место поля — проверить на месте]**
- **Кнопка → раздел:** нажмите на кнопку, в поле **«Действие по клику»** выберите **«Перейти к блоку»** и укажите нужный блок. Способ открытия — **«в этом же окне»**. **[проверено]**
- Если в пункте меню нет варианта «Перейти к блоку», впишите в поле ссылки `#имя_якоря`, например `#plans`. **[проверить на месте]**
- **Сохранить** → изменения публикуются автоматически. Если не появились: облако → «Опубликовать сайт». **[проверено]**

| Раздел | Якорь |
| --- | --- |
| Шапка / первый экран | `top` |
| Что можно разместить | `services` |
| Подход к качеству | `approach` |
| Панель управления | `panel` |
| Варианты размещения | `plans` |
| Как начать | `start` |
| Вопросы и ответы | `faq` |
| Обратная связь | `contact` |

**Заголовок:** Выберите направление, конфигурацию подберём под задачу

| Карточка | Текст | Кнопка → действие |
| --- | --- | --- |
| **Доступный старт** | Линейка на Ryzen 7 7700. Для небольших проектов, которым важен бюджет и подходящий объём ресурсов. | «Обсудить старт» → блок `contact` |
| **Повышенная производительность** | Линейка на Ryzen 9 7950X3D. Для более требовательных задач. Итоговый результат зависит от выделенных ресурсов и самой нагрузки. | «Обсудить нагрузку» → блок `contact` |
| **Индивидуальная конфигурация** | Для нескольких сервисов, нестандартного стека или особых требований. Начнём с описания вашей задачи. | «Обсудить конфигурацию» → блок `contact` |

**Текст под карточками** (отдельный блок «Текст»): Объём памяти, диска, процессорные лимиты, дополнительные возможности и стоимость определяются при подборе. Модель процессора указывает на серверную линейку и не означает выделение всего процессора одному проекту.

**Не добавлять:** цены, скидки, «до N игроков», конкретные ГБ.

### Блок 8. Вопросы и ответы — якорь `faq` (аккордеон, дополнительная функция №1)

- **Где взять:** категория **«Текст»** → **«Текст с раскрывающимися пунктами»** или его варианты (с иконкой, в рамке, с разделителем). **[проверено]**
- Раскрытие **не работает в режиме редактирования**. Проверяйте в «Предпросмотре» или на опубликованном сайте. **[проверено]**
- Фон: `#FFFFFF`.

**Заголовок:** Вопросы и ответы

| Вопрос | Ответ |
| --- | --- |
| Что выбрать для первого Minecraft-сервера? | Начните с описания версии, сборки и ожидаемой нагрузки. Моды, плагины и настройки мира влияют на требования, поэтому одного числа игроков недостаточно. |
| Обязательно ли уметь администрировать Linux? | Для основных действий с игровым сервером предусмотрена веб-панель. Работа с VPS и нестандартными приложениями может требовать навыков администрирования. |
| Можно ли разместить бота или сайт? | Да, такие сценарии входят в концепцию сервиса. При подборе нужно уточнить язык, среду запуска, базу данных и другие зависимости. |
| Что делать, если проект вырос? | Сначала оценить использование ресурсов и настройки, затем обсудить подходящую конфигурацию. Возможность и порядок переноса зависят от услуги. |
| Гарантирует ли DDoS-защита отсутствие любых сбоев? | Нет. Она предназначена для снижения риска сетевых атак. Стабильность зависит также от нагрузки, настроек приложения и внешних условий. |
| От чего зависит стоимость? | От выбранного направления, выделенных ресурсов и дополнительных возможностей. Поэтому точные условия подбираются под задачу. |

Если пунктов в блоке меньше шести, добавьте карточки: «Редактировать» → «Карточки» → «Добавить».

### Блок 9. Обратная связь — якорь `contact`

- **Где взять:** категория **«Формы»** → блок со **встроенной** CRM-формой (форма на странице, не всплывающая), лучше вариант «текст слева, форма справа».
- В настройках блока выберите форму **«Заявка на подбор хостинга»** (создаётся по `FORM_CRM.md`).

**Заголовок:** Расскажите, что хотите запустить

**Текст:** Укажите направление и коротко опишите задачу. Например: Minecraft с модами, Telegram-бот на Python или небольшой сайт с базой данных.

**Заметка мелким шрифтом:** Учебный демонстрационный сайт. Форма передаёт заявку автору работы; оплата и оформление хостинга здесь не производятся.

## Шаг 4. Замены, если штатного блока нет

ТЗ разрешает заменить дополнительную функцию штатным решением, у которого есть проверяемое действие.

| Если нет… | Замена | Как сделать |
| --- | --- | --- |
| Галереи с увеличением | **Форма во всплывающем окне** | Кнопка «Обсудить проект» в шапке → «Действие по клику» → **«Открыть CRM-форму»** → та же форма. **[проверено]** Встроенная форма в `#contact` остаётся. Три картинки панели остаются обычной галереей с подписями |
| Галереи с увеличением (вариант 2) | **Вкладки с описанием вариантов** | Блок с вкладками (если есть в библиотеке): «Доступный старт / Повышенная производительность / Индивидуальная конфигурация» с текстами из блока 6. **[проверить на месте]** |
| Аккордеона | (не требуется: блок «Текст с раскрывающимися пунктами» есть в стандартном наборе) | — |

Суперблоки на бесплатном тарифе ограничены. Собственный HTML/JS для этой работы не нужен, не используйте его.

## Шаг 5. Публикация и проверка

1. Облако → **«Опубликовать сайт»**.
2. Откройте публичную ссылку **в окне инкогнито**, без входа в аккаунт.
3. Пройдите чек-лист из `CHECKLIST_AND_REPORT.md`.
4. Сделайте скриншоты: компьютер (1440 px) и телефон (360 px). В Chrome: F12 → значок телефона → ширина 360.
