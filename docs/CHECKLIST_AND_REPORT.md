# Чек-лист проверки и шаблон отчёта

Проверяйте **опубликованную** страницу в окне инкогнито, а не предпросмотр редактора. Отмечайте `[x]` только то, что действительно проверено.

## 1. Чек-лист

**Доступ и состав**
- [ ] Страница открывается по публичному адресу `https://….bitrix24site.ru/` без входа в аккаунт.
- [ ] Тариф бесплатный, не «Демо»; публичная ссылка показывает последнюю сохранённую версию.
- [ ] Все 8 разделов на месте: первый экран · Что можно разместить · Подход · Панель · Варианты · Как начать · Вопросы · Обратная связь + подвал.
- [ ] Минимум 3 содержательных изображения (разрез, фрагмент разреза, стойка, 3 экрана панели), у каждого есть alt.
- [ ] Дизайн по `DESIGN.md`: медные кнопки, светлая шапка, нет градиентов, теней, анимации появления и иконок-эмодзи; Minecraft крупно, остальные направления строками; варианты — полосы, средняя тёмная.
- [ ] На экранах панели видна надпись «Пример интерфейса».

**Кнопки и меню**
- [ ] Меню: Возможности → `services`, Панель → `panel`, Варианты → `plans`, Вопросы → `faq`.
- [ ] «Обсудить проект» → форма.
- [ ] «Посмотреть варианты» → `plans`, «Посмотреть панель» → `panel`.
- [ ] 4 × «Обсудить задачу», «Уточнить возможности…», «Обсудить старт / нагрузку / конфигурацию», «Рассказать о проекте» → форма.
- [ ] В подвале «Наверх» → шапка, «Обработка данных формы» → форма (и текст соглашения открывается из формы).
- [ ] Шапка не закрывает заголовок раздела после перехода. Если закрывает, отключите фиксацию шапки или увеличьте верхний отступ у блоков.

**Форма**
- [ ] Пустые обязательные поля не отправляются.
- [ ] Некорректный email не отправляется.
- [ ] Тестовая заявка `LAB1-TEST-…` отправлена, показано «Заявка получена.»
- [ ] Эта же заявка найдена в CRM, все поля совпадают.
- [ ] Галочка согласия не отмечена заранее, текст соглашения открывается.
- [ ] Нет платных СМС, рассылок и писем на чужие адреса.

**Дополнительные функции**
- [ ] FAQ: ответ раскрывается и сворачивается мышью; проверено также с клавиатуры (Tab → Enter), если блок это поддерживает.
- [ ] Галерея: картинка увеличивается, закрывается, листается. Либо работает согласованная замена: форма во всплывающем окне или вкладки.

**Адаптивность** (Chrome → F12 → режим устройства)
- [ ] 360 px: нет горизонтальной прокрутки, меню-«бургер» работает, кнопки удобны, форма целиком на экране.
- [ ] 768 px: нет перекрытий и обрезанных блоков.
- [ ] 1440 px: контент ровный, ширина около 1100–1200 px.

**Обезличенность и честность**
- [ ] Нет названия, логотипа, домена или контактов реального хостинга и нет выдуманного бренда.
- [ ] Нет цен, скидок, отзывов, счётчиков клиентов, «100 %», «без лагов», «безлимит».
- [ ] Нет вымышленных адресов, телефонов, email и пустых иконок соцсетей.
- [ ] Не осталось шаблонного текста («Lorem ipsum», «Ваша компания» и т. п.).
- [ ] Заголовок вкладки, описание, favicon и превью ссылки без чужого бренда.

## 3. Что передать по завершении

1. Публичная ссылка: ___
2. Где редактировать: Битрикс24 → **Сайты и магазины → Сайты → «Хостинг для проектов»**.
3. Скриншоты: компьютер (1440 px) и телефон (360 px) **опубликованной** страницы.
4. Результат проверки формы: в каком разделе CRM найдена заявка `LAB1-TEST-…`, скриншот со скрытым email.
5. Заполненная карта соответствия (раздел 2).
6. Дополнительные функции: FAQ-аккордеон; галерея с увеличением или замена.
7. Реальные ограничения, только фактические. Например: «на бесплатном тарифе активен один сайт», «галерея без увеличения → заменена всплывающей формой», «направление указывается текстом, а не списком».

## 4. Сценарий показа преподавателю (1–2 минуты)

1. **(15 с)** «Тема — одностраничный сайт об услуге хостинга для игровых серверов, ботов, сайтов и VPS. Сделан на Битрикс24.Сайты, бесплатный тариф». Открыть публичную ссылку.
2. **(30 с)** Первый экран → нажать «Посмотреть варианты» → вернуться через меню «Возможности» → показать карточки направлений и блок «Подход».
3. **(20 с)** Меню «Панель» → открыть картинку в увеличенном виде, пролистать, закрыть (доп. функция №2).
4. **(15 с)** Меню «Вопросы» → раскрыть и свернуть пару ответов (доп. функция №1).
5. **(25 с)** «Обсудить проект» → нажать «Отправить» с пустыми полями (валидация) → заполнить с меткой `LAB1-TEST-<время>` → «Заявка получена.»
6. **(15 с)** В соседней вкладке открыть CRM → найти эту заявку по метке.
7. (по желанию) Показать мобильную версию: F12 → 360 px → меню-«бургер».
