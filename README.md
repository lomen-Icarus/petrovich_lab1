# Лабораторная работа № 1 — одностраничный сайт «Хостинг для проектов»

Тема: обезличенный хостинг-сервис для игровых серверов (прежде всего Minecraft), ботов, небольших сайтов и приложений, VPS.
Платформа сдачи: **Битрикс24.Сайты**, бесплатный тариф.

## Статус

| Этап | Состояние |
| --- | --- |
| Структура, тексты, якоря, карта сборки по блокам | ✅ готово — `docs/BUILD_MAP.md` |
| Изображения (4 содержательных + favicon + превью ссылки) | ✅ готово — `images/` |

| **Сборка и публикация в Битрикс24** | ⏳ **не выполнено**: нужен вход в ваш аккаунт Битрикс24 |
| **Тестовая заявка, найденная в CRM** | ⏳ после публикации |

> ⚠️ `preview/index.html` — **только эталон** внешнего вида и поведения. Сам по себе он требование лабораторной не выполняет: нужен сайт, собранный и опубликованный в конструкторе Битрикс24.

## Что осталось сделать (в аккаунте Битрикс24)

1. Проверить, что тариф **бесплатный, а не «Демо»**: в демо-режиме публикация и CRM-формы недоступны.
2. Создать сайт, сделать черновик с CRM-формой, **подтвердить телефон по СМС** (запрашивается при первой форме), опубликовать и проверить, что тестовая заявка дошла.
3. Собрать 10 блоков по `docs/BUILD_MAP.md`, загрузить картинки из `images/`.
4. Пройти чек-лист и заполнить отчёт по `docs/CHECKLIST_AND_REPORT.md`.

## Состав репозитория

```
docs/
  BUILD_MAP.md              пошаговая сборка: настройки сайта, якоря, 10 блоков с текстами, замены
  FORM_CRM.md               CRM-форма: поля, списки, соглашение, сообщения, тест LAB1-TEST
  CHECKLIST_AND_REPORT.md   чек-лист проверки, карта соответствия, сценарий показа
images/
  hero-servers.jpg          первый экран — серверная иллюстрация (без текста)
  panel-overview.png        «Пример интерфейса»: обзор сервера и ресурсы
  panel-files.png           «Пример интерфейса»: файлы и настройки
  panel-console.png         «Пример интерфейса»: консоль и запуск
  icon-server.png           пиктограмма сервера (favicon / логотип в шапке)
  og-preview.jpg            превью ссылки для мессенджеров
  src/*.svg                 исходники изображений
preview/index.html          прототип страницы (эталон)
screenshots/                скриншоты прототипа: 1440 / 768 / 360 px
tools/make-images.cjs       генерация изображений из SVG
tools/check-preview.cjs     автопроверка прототипа + скриншоты
```

Все изображения нарисованы с нуля: в них нет чужих логотипов, доменов, IP-адресов и реальных данных.

## Пересборка изображений и проверка прототипа

```bash
NODE_PATH=$(npm root -g) node tools/make-images.cjs     # нужен playwright
NODE_PATH=$(npm root -g) node tools/check-preview.cjs   # 22 проверки + скриншоты в screenshots/
```

Автопроверка прототипа покрывает: отсутствие горизонтальной прокрутки на 1440/768/360 px, все якоря, 8 разделов, единственный H1, ≥3 изображений с alt, переход по меню (в том числе мобильному), FAQ мышью и с клавиатуры, галерею (открыть / листать / закрыть по Esc и ×), валидацию формы (пустая, неверный email, корректная).
